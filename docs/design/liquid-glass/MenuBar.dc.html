SwiftUI · the menu-bar panel is the whole launcher

Start, watch and stop the jam here. The panel is the system’s glass, so nothing inside adds glass. A setup window opens only when a step fails (next board).

  1. 1
    MenuBarExtra { JamPanel() } label: { Image(jam.isLive ? "jar.fill" : "jar") } .menuBarExtraStyle(.window)System panel material. No .glassEffect() inside it.
  2. 2
    Button("Start the jam", systemImage: "play.fill") { jam.start() } .buttonStyle(.borderedProminent) .controlSize(.large) .tint(.nimbrungRed)The one prominent control. .nimbrungRed is #D62B30 in every state: no live tint, no gradient.
  3. 3
    ForEach(jam.steps) { StepRow(step: $0) } Button("Cancel") { jam.cancel() } .buttonStyle(.bordered)ProgressView().controlSize(.small) while a step runs, checkmark.circle.fill when it is done.
  4. 4
    NowPlayingRow() Label("Live · \(jam.guestCount) guests", systemImage: "dot.radiowaves.left.and.right")A label, not a control. The live dot is the only motion.
  5. 5
    Button("Copy link", systemImage: "doc.on.doc") .buttonStyle(.bordered) .controlSize(.small)Works while stopped, so the link can go out before the party.
  6. 6
    Button("Stop the jam…", systemImage: "stop.fill") { if jam.guestCount > 0 { confirmStop = true } else { jam.stop() } }The ellipsis says it asks first. With nobody connected it stops at once.
  7. 7
    .confirmationDialog("Stop the jam?", isPresented: $confirmStop) { Button("Stop the jam", role: .destructive) { jam.stop() } } message: { Text("\(jam.guestCount) guests will be disconnected.") }Quit (⌘Q) while live asks the same question.
  8. 8
    Image(jam.isLive ? "jar.fill" : "jar") .renderingMode(.template)Template glyph: the jar fills while starting and stays full while live.
