# Security

Please don't report security problems in a public issue.

Use GitHub's private reporting instead: **Security → Report a vulnerability**
on [dezeto/nimbrung](https://github.com/dezeto/nimbrung/security/advisories/new).
Say what you found, how to reproduce it, and what someone could do with it.

Things worth reporting: a guest acting as host without the host key, getting
past a block, removing or reordering other people's songs beyond what the
rules allow, or reaching the YouTube Music plugin API through Nimbrung.

Nimbrung is a hobby project, so fixes go into the latest version only.
